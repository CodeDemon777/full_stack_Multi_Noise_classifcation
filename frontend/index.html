💻 Local & Cloud Deployment Guide (Vercel + Render)
Instructions to host the frontend on Vercel and backend on Render within free tier limits.

1. Deploy Backend to Render (Free Tier)

1. Connect GitHub repo to Render.com.
2. Select Web Service.
3. Build Command: pip install -r requirements.txt
4. Start Command: gunicorn --workers 1 --threads 2 --timeout 120 app:app

2. Deploy Frontend to Vercel (Free Tier)

1. Connect repo to Vercel.com.
2. Set Root Directory to frontend/ or root.
3. Paste your Render backend URL into the top gateway configuration bar.
