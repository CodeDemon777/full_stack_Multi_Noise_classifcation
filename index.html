🧬 5-Level Nested U-Net (UNet++) Architecture
Comprehensive deep learning methodology for pixel-level multi-noise segmentation, dense skip pathways, and deep supervision on low-dose computed tomography (LoDoPaB-CT).

🕸️ Nested Dense Skip Pathways

Unlike standard U-Net with simple skip connections, UNet++ redesigns skip pathways with dense convolution blocks along nested pathways ($X^{i,j}$), capturing multi-scale feature hierarchies and bridging the semantic gap between encoder and decoder feature maps.

⚡ Deep Supervision Loss

Aggregates multi-level loss across all intermediate decoder nodes ($X^{0,1}, X^{0,2}, X^{0,3}, X^{0,4}$). Enables model pruning at inference time without retraining and accelerates gradient flow to early layers.

🎯 Multi-Task Hybrid Loss

Optimized with a combination of Weighted Cross-Entropy Loss, Multi-Class Soft Dice Loss, and Focal Loss to combat severe class imbalance between large clean lung tissue and localized high-frequency artifacts.

Mathematical Formulation of Node Aggregation

Let $x^{i,j}$ denote the output of node $X^{i,j}$ where $i$ indexes downsampling layer and $j$ indexes skip pathway:

$$x^{i,j} = \mathcal{H}\left(\left[ [x^{i,k}]_{k=0}^{j-1}, \mathcal{U}(x^{i+1, j-1}) \right]\right)$$

where $\mathcal{H}(\cdot)$ is a convolution operation followed by BatchNorm and ReLU, $\mathcal{U}(\cdot)$ is an upsampling layer with bilinear interpolation, and $[\cdot]$ denotes channel-wise concatenation.

Deep Supervision Formulation

$$\mathcal{L}_{DS} = \sum_{j=1}^{4} w_j \cdot \left( \mathcal{L}_{CE}(Y, \hat{Y}^{0,j}) + \lambda_{Dice} \mathcal{L}_{Dice}(Y, \hat{Y}^{0,j}) + \lambda_{Focal} \mathcal{L}_{Focal}(Y, \hat{Y}^{0,j}) \right)$$
